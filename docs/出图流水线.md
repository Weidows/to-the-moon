# 出图流水线

本仓库不跑 ComfyUI。所有插画都在一台出图机（下称 `<gpu-host>`）上生成，
跑图脚本住在同级仓库 `aigc/comfyui` 的 `pipelines/` 下，经 `ops/deploy.sh`
平铺部署到服务器的 `/root/pose_pipeline/`，产物落 `/root/ComfyUI/output/`。

| 阶段 | 输入 | 在哪跑 | 落地 |
| --- | --- | --- | --- |
| ① 形象图 | `public/人物设定.md` | `comfyui: pipelines/character-sheet/charbatch.py` | `/root/ComfyUI/output/character-sheet/<model>/` |
| ② 镜头图 | `人物设定.md` + `src/tools/jobs/pl_*.json` | `comfyui: pipelines/scene/scene_batch.py` | `/root/ComfyUI/output/scene/moss/` |
| ③ 成品 | ②拉回来的 `<job>_<seed>.png` 放 `.tmp/renders/` | `src/tools/to_web.py` | `public/img/`（scenes 直接 import） |

## 引擎

MOSS-Image：`moss_image_sft_int8_convrot` ＋ `moss_text_encoder`（CLIP type=`moss_image`）
＋ `flux2-vae_small`，`KSampler(er_sde/simple, 30 步, cfg 2.5)`。
1792×1008 实测 **18.0 s/张**，20 个镜头约 6 分钟。

角色候选那一路用的是 Qwen-Image-2.1，客户端见 `src/tools/comfy.py`（1024² 约 12 s/张）。

## 角色一致性靠参考图

有角色的镜头走 `TextEncodeMOSSImageEdit`：参考图进**文本编码器**，不接 VAE、不加 edit LoRA。
参考图放 `input/work/scene-refs/`，强度按镜头选：

- 0.9–0.95 成人特写
- 0.8–0.85 老年角色
- 0.75 双人同框
- **不给** 孩子镜头、背影镜头、空镜

给成人形象图哪怕是孩子镜头，也会在画面里塞进一张成人脸。

## 提示词是唯一真源

源头是 `src/tools/jobs/pl_*.json`。改人物设定时必须回来改这 20 个 job，
再重新生成 `comfyui` 里 `pipelines/scene/tothemoon_scenes.json` 的对应条目——
参考图对了、文字错了，模型照样按文字画。

## 拉图与接入

按 `<job>_<seed>.png` 命名放进 `.tmp/renders/`（`to_web.py` 用 `latest()` 挑最新一张），然后：

```bash
python src/tools/to_web.py --check   # 哪些 img/ 还没有来源
python src/tools/to_web.py           # .tmp/renders → public/img
```

`jobs/` 的 20 个 job 覆盖 29 个镜头引用中的 20 个，job→文件名的映射就是
`to_web.py` 的 `TARGETS`；剩下 9 个是官方截图/壁纸，直接放在 `public/img/`。

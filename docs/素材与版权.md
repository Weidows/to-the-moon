# 素材与版权

《去月球 / To the Moon》的角色、剧情、音乐版权归 **Freebird Games / Kan Gao** 所有。
本片是非商业同人致敬作品，不用于任何营收。

本仓库自己的代码与生成素材（`public/gen/`、`public/img/` 里由流水线生成的镜头）可以随意阅读；
游戏原作的截图、音乐不随仓库分发，见下。

## 游戏内截图

- 来源：Steam 商店页 To the Moon（appid 206440）
  <https://store.steampowered.com/app/206440/>
- 版权归 Freebird Games。**14 张原图不随仓库分发**（`.gitignore` 里的 `public/online/steam/`），
  需要时自行下载后放进该目录。

## 官方壁纸 / 同人美术

- 来源：Fandom 的 To the Moon Wiki <https://tothemoon.fandom.com>
- 抓取脚本 `src/tools/fetch_fandom.py`，清单 `src/tools/fandom_images.json`
  里每张图都带 `descriptionurl`，可逐张回查原始页面。
- 成品在 `public/online/`（保留在仓库里，作同人创作参考）。

## 音轨

- PianiCast 的钢琴翻奏《For River》，312 s，与片长对齐。
- **不进仓库**。要重新渲染请自备音轨放到 `public/for-river.mp3`，否则
  `npm run render` 会因缺资源失败。

## 字体

- `public/fonts/zpix.woff2`，Zpix 最像素，作者 SolidZORO，OFL 授权。
- 这是 12 px 点阵字体，字号必须是 12 的倍数（`src/theme.ts` 的 `snap()` 负责取整），
  否则字形网格被重采样会糊。

## 其它

- 剧情长文、人物设定、旁白文稿在 `public/`：`万字诠释…md`、`主线描述.md`、`人物设定.md`、`script.md`。
